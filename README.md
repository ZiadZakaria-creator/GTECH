# GTECH — متجر الإلكترونيات

تصميم موقع متجر إلكترونيات عربي (RTL) بواجهة داكنة عصرية.

## التشغيل
افتح `index.html` مباشرة في المتصفح — لا يحتاج أي تثبيت.

## المحتوى
- هيدر ثابت مع بحث وسلة ومفضلة وقائمة للموبايل
- قسم رئيسي (Hero) مع إحصائيات متحركة
- الأقسام، المنتجات مع فلترة وبحث، سلة تسوق جانبية (تُحفظ في المتصفح)
- عرض بعدّاد تنازلي، شريط الماركات، آراء العملاء، النشرة البريدية، والفوتر
- متجاوب بالكامل مع الموبايل والتابلت
