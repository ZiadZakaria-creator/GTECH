أسعار الشحن للعميل

السعر اللي العميل بيدفعه حسب محافظته. شيل علامة "بنوصّل" من أي محافظة مش عايز توصّلها.

💳 الدفع بالتحويل

اكتب البيانات اللي العميل هيحوّل عليها. أي طريقة تسيبها فاضية مش هتظهر للعميل في صفحة الدفع.

📦 الربط مع بوسطة

بعد ما تحط المفتاح، هيظهر في كل طلب زرار "ابعت لبوسطة" بيعمل الشحنة عندهم ويجيب رقم التتبع، والعميل يشوفه في "طلباتي" وفي الإيميل.

المفتاح بتجيبه من حسابك في بوسطة: Settings ← API Integration ← Create API Key. المفتاح بيتحفظ في قاعدة البيانات ومحدش يقدر يشوفه غير الأدمن.

تقييمات العملاء الحقيقية زي ما بتظهر في صفحات المنتجات. لو فيه تقييم سبام أو فيه ألفاظ، امسحه من هنا.
