# صور المنتجات

حط صور المنتجات هنا، وسمّيها برقم المنتج ورقم الصورة:
`1-1.jpg`, `1-2.jpg`, `2-1.jpg` ...

بعدها اكتب المسارات في `data.js` جوه `images` بتاع المنتج:

```js
images: ["images/1-1.jpg", "images/1-2.jpg"],
```

- المقاس المفضل: مربع 1000×1000 بكسل، JPG أو WebP، أقل من 300KB للصورة.
- أول صورة هي اللي بتظهر في كارت المنتج والسلة.
